# RemoteHub Desktop 0.1.0-beta.2

本次预发布重点优化终端、SFTP、数据库界面，并新增本地 Shell、服务器概览和 Codex 用量监控。
# RemoteHub Desktop 0.1.0-beta.3

基于最新 main（合并请求 #6，`f7ab7ae`）重新构建的预发布版本，保留 beta.1 下载。

beta.2 自动发布被 macOS 启动验收拦截；本版本修复后重新走完整四目标构建，不覆盖旧标签或安装包。

## 本次更新

- 侧栏间距、分组图标/计数、拖动调整大小、连接双击打开与右键操作。
- 新建连接页测试入口、数据库类型图标和工作区连接概览。
- 修复新建数据库连接测试时未传递临时密码的问题。
- SSH/SFTP 组合视图、本地与远程文件浏览、可调整方向和分隔比例。
- 日间/夜间主题、终端右键粘贴和界面细节优化。
- 本地终端、服务器状态及 Codex 状态入口；在线监控依赖目标环境，未包含在离线验收范围内。
- 安装包使用自定义应用图标，补齐 node-pty 运行资源与原生依赖重建。
- 修复 macOS PTY 辅助程序缺少执行权限造成的本地终端启动失败。
- 打包后启动检查新增 PTY 真实进程收发及应用图标检查。

## 选择下载文件

- Windows 10/11 x64：`win-x64-setup.exe` 为安装版，`win-x64-portable.exe` 为免安装版。
- macOS Intel：`mac-x64.dmg`；Apple Silicon：`mac-arm64.dmg`。
- Linux x64：`linux-x86_64.AppImage`，赋予执行权限后运行。
- 无需另装 Node.js、npm 或 pnpm。安装包不包含个人连接、密码、私钥和数据库。

## 新增与优化

- 新增可选择启动目录的本地 Shell，支持中文目录以及 Codex 等交互式命令。
- SSH 与本地 Shell 新增 Codex 用量面板，显示 5 小时、7 天剩余额度、重置时间和最近 14 天 Token 消耗图。
- SSH 新增服务器概览，展示 CPU、内存、磁盘、网络和进程状态；SFTP 文件页支持独立开启、关闭和多方向停靠。
- 连接列表支持折叠；文件与文件夹图标、右键菜单关闭行为和数据库工具栏图标得到优化。
- 完善浅色/深色主题下数据库、搜索框、终端和文件页面的颜色一致性。
