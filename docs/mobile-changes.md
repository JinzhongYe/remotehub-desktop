## 修改内容

- Android/iOS 共用 Tauri 服务入口。Android 使用 KeyStore，iOS 使用设备本地 Keychain 保存密码和私钥口令；剪贴板通过原生接口读写。
- 首次 SSH 指纹确认纵向排列，确认按钮保持在屏幕内；SSH 连通前不切换到空的 SFTP 内容区。
- SSH 终端按输出流保留未完成的 UTF-8 字节；提供 Ctrl、Esc、Tab、Ctrl+C 和方向键，手机保留完整错误信息。
- 返回操作仅作用于当前标签。原生恢复前台、网页恢复可见和网络恢复会触发只读连接检查，不自动重放用户 SQL、写操作或传输。
- 触屏平板使用移动布局。结果行、分页栏、关闭按钮和分组操作增大；数据库低频操作移到文字菜单，文件操作移到每行菜单。移动端对象树保持展开。
- 连接和分组提供上移/下移按钮。连接排序复用已有持久化接口。
- MySQL 与 PostgreSQL 使用同一 SSL 模式字段。新建移动连接默认严格校验；旧 Android MySQL 配置未指定模式时要求 TLS，允许用户明确选择关闭或只加密模式。桌面 MySQL 同步遵守该字段。
- 编辑已有数据库连接且密码留空时，认证测试复用已保存密码；勾选清除密码时测试使用空密码。
- 远程文本与上传先写权限受限的临时文件，写完关闭后才替换。覆盖保留目标权限与所有者，不支持 `posix-rename@openssh.com` 的服务器拒绝安全覆盖并保留原文件。进程被杀时可能留下 `.remotehub-*.tmp` 文件。
- Android/iOS 对非分页返回语句完整读取执行结果，只保留前 500 行并显示截断说明，不重新执行语句。
- iOS 从文件选择器导入副本，下载与 CSV 完成后通过系统文档导出界面保存。
- 新增手动触发的移动构建工作流，未触发。UTF-8、返回层、前台恢复、MySQL TLS 和平台接口回归用例已补充，未执行。

## 建议测试顺序

1. 375px 手机、768px 平板、横屏与软键盘打开；深浅主题、中英文都检查指纹、菜单、分页和弹窗。
2. 首次 SSH 连接与 SFTP 入口、拒绝/信任指纹、错误密码、断开/重连、中文输出和辅助键。
3. 切换多个标签后使用 Android 返回键；后台页面不能消费当前页面的返回操作。
4. 上传、下载、重命名、文件编辑；保存中断网时原远程文件应完整，草稿应保留；不支持安全替换的服务器应显示错误。
5. MySQL/PostgreSQL 三种 SSL 模式、已存密码的编辑表单测试、SQL 查询、草稿保存、CSV 导入导出与大量 RETURNING 结果。
6. 锁屏、切换应用、Wi-Fi/移动数据切换后检查连接状态；应用不应自动重新执行写操作。
7. iOS 重启应用后读取 Keychain 凭据，文件选择与导出取消、多标签和软键盘布局。

## 启动入口与边界

- Android：沿用 `npm run android:dev`。
- iOS：工程位于 `src-tauri/gen/apple/remotehub.xcodeproj`，入口为 `npm run ios:dev`。真机运行需要自己的 Apple 开发团队与签名配置；设置 `APPLE_DEVELOPMENT_TEAM` 或 Tauri `bundle.iOS.developmentTeam`。
- 本机 CocoaPods 安装在用户 Ruby gem 目录。若当前终端找不到 `pod`，将 `$HOME/.gem/ruby/2.6.0/bin` 加入 PATH，或使用自己的 CocoaPods/Ruby 环境。
- FTP、SQLite、数据库 SSH 隧道、本地 Shell、串口、目录传输与传输暂停/重试仍属于移动端未支持功能，本轮没有新增这些模块。
- 本轮未实现系统级后台保活、进程被杀后的会话续接或传输断点续传；前台恢复只检查现有会话。
- 安全替换需要服务器支持 OpenSSH POSIX rename 扩展与允许保留目标权限/所有者；服务器策略不允许时保存会失败并保留原文件。
